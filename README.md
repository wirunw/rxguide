คู่มือประกอบการปฏิบัติงานสำหรับเภสัชกรร้านยา ตั้งแต่การซักประวัติ การเลือกยา การเลือกยาสามัญหรือชื่อการค้า จนถึงบทพูดให้คำแนะนำ

## เนื้อหา

1. วิธีใช้คู่มือ
2. การซักประวัติ (WWHAM, QuEST, SCHOLAR, คำถามบังคับ, red flag)
3. ผังตัดสินใจหลัก และการเลือกยาสามัญ/ชื่อการค้า
4. แนวทางรายโรค 21 กลุ่มอาการ พร้อมผังตัดสินใจและบทพูด
5. กฎหมายหน้าเคาน์เตอร์
6. ยาตีกัน สมุนไพร และผู้ป่วยกลุ่มพิเศษ
7. ขนาดยาเด็ก
8. คลังบทพูด
9. แหล่งอ้างอิงและข้อจำกัด

## การใช้งาน

เปิดผ่าน GitHub Pages หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์ แล้วกรอกรหัสผ่านที่ได้รับจากผู้ดูแล

เนื้อหาในไฟล์ถูกเข้ารหัสด้วย AES-256 ([StatiCrypt](https://github.com/robinmoisson/staticrypt)) เบราว์เซอร์จะถอดรหัสเมื่อกรอกรหัสผ่านถูกต้อง ไฟล์ใน repository นี้ไม่มีเนื้อหาที่อ่านได้และไม่มีรหัสผ่านเก็บอยู่ ต้นฉบับที่ไม่เข้ารหัสเก็บไว้นอก repository

การเปิด GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`

## การอัปเดตเนื้อหา

แก้ต้นฉบับ แล้วเข้ารหัสใหม่ด้วยคำสั่ง

```
npx staticrypt@3.5.4 index.html -p "<รหัสผ่าน>" --short -d out --remember 30
```

นำไฟล์ `out/index.html` มาแทนไฟล์เดิมใน repository ห้าม commit ต้นฉบับที่ยังไม่เข้ารหัส

## ข้อจำกัด

ใช้ประกอบการตัดสินใจทางวิชาชีพ ไม่ทดแทนเอกสารกำกับยาและดุลพินิจของเภสัชกร รายละเอียดข้อจำกัดของแหล่งข้อมูลอยู่ในบทที่ 9 ของคู่มือ
